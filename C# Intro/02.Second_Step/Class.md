## Class:
### A class in C# is a fundamental bulding block of OOP. It serves as a blueprint for maintaining fields, properties, methods, constructors, delegates, and other members. A class organizes related data and functions together, enabling modular and reusable code.

## Main Points:
#### Field(s) : fields are variables that belong to a class. They represent the data that an object of the class can hold.

#### Properties: that provides controlled access to a class's fields using get and set accessors

#### Constructor(s): it's a special method that is used to initialize objects. it is called when an instance of the class is created.

#### Method(s): are reusable block of code that perform specific tasks

#### Delegate(s): in C# is a type-safe pointer to a method with a specific signature
